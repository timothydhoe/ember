# iTerm2

Three presets, one per contrast level:

1. Settings -> Profiles -> Colors -> Color Presets -> Import -> pick `alight-hard.itermcolors`, `alight-medium.itermcolors`, or `alight-soft.itermcolors` (import as many as you want)
2. Color Presets -> select the one you imported (shows up as **alight-hard** / **alight-medium** / **alight-soft**)

Verify: `uv run scripts/live_show_swatches.py` from `alight/`

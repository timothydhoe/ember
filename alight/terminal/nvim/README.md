# Neovim

Local `lazy.nvim` plugin, pointed at this folder:

```lua
{
  "alight",
  dir = "/path/to/ember/alight/terminal/nvim",
  name = "alight",
  lazy = false,
  priority = 1000,
  config = function()
    vim.cmd.colorscheme("alight")
  end,
}
```

No install step beyond that — `colors/alight.lua` is already committed and regenerated by `export_nvim.py`.

Contrast: set `vim.g.alight_contrast` to `"hard"`, `"medium"`, or `"soft"` before `:colorscheme alight` loads. Defaults to `"medium"` if unset. One file covers all three -- no separate variant files to pick between, unlike the static terminal-app configs.

```lua
vim.g.alight_contrast = "soft"
vim.cmd.colorscheme("alight")
```

Covers: base UI, diagnostics, diff, Treesitter captures, gitsigns.nvim, snacks.nvim indent guides, blink.cmp. See `ember-nvim/` for the full config this is built for.

Verify: `uv run scripts/export_nvim.py` from `alight/` re-runs the WCAG contrast audit against the current palette.
